# سجل حضور العمال — خالد شام للإنشاءات

نظام حضور وانصراف للعمال، بيدعم أكتر من ورشة وأكتر من مسؤول ورشة في نفس الوقت، وكل البيانات بتتزامن أونلاين (Firebase) عشان كل الناس تشوف نفس البيانات لحظة بلحظة.

## إزاي النظام شغال

- **صاحب الشركة**: بيدخل بكود خاص بيه (owner PIN)، وبيشوف كل الورش مجمعة: "اليوم"، "السجل"، "التقارير"، وبيضيف/يمسح الورش وكود كل ورشة.
- **مسؤول الورشة (فورمان)**: بيدخل بكود ورشته بس، وبيشوف عماله هو بس، ويسجل حضور وانصراف بدوسة على الاسم، ويضيف عمال جداد لورشته.

## خطوات التجهيز (مرة واحدة بس)

### 1) اعمل مشروع Firebase مجاني

1. روح على https://console.firebase.google.com
2. دوس **Add project** وسمّي المشروع أي اسم (مثلاً `khaled-sham-attendance`).
3. مش لازم تفعّل Google Analytics، سيبها كده وكمّل.

### 2) فعّل قاعدة البيانات (Firestore)

1. من القايمة الجانبية: **Build → Firestore Database**.
2. دوس **Create database**، اختار أي location قريب (مثلاً `eur3` أو `me-central1`)، وابدأ في **وضع الاختبار (test mode)** مبدئيًا.
3. بعد ما تتعمل، روح لتبويب **Rules** فوق، وامسح اللي موجود وحط القواعد دي بدالها، ثم دوس **Publish**:

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /sites/{doc} { allow read, write: if true; }
    match /workers/{doc} { allow read, write: if true; }
    match /records/{doc} { allow read, write: if true; }
  }
}
```

> ملحوظة: القواعد دي مفتوحة عشان النظام بسيط ومحصور على كام موظف تعرفهم، والحماية الأساسية هنا هي كود الـ PIN. لو حبيت حماية أقوى بعدين (منع أي حد يعدل البيانات من برا الموقع)، ده ممكن نضيفه لاحقًا بمصادقة حقيقية.

### 3) هات إعدادات الويب (Web config)

1. من صفحة المشروع الرئيسية، دوس أيقونة **</>** (Web app)، وسمّيها أي اسم.
2. مش لازم Firebase Hosting، تجاهله.
3. هيديك كائن `firebaseConfig` فيه قيم زي `apiKey`, `projectId`, إلخ.
4. افتح ملف `src/firebase.js` في المشروع، واستبدل القيم اللي مكتوبة "ضع_...._هنا" بالقيم اللي جتلك.

### 4) غيّر كود صاحب الشركة (Owner PIN)

في نفس ملف `src/firebase.js`، غيّر القيمة:

```js
export const OWNER_PIN = "9999";
```

لأي رقم تحبه إنت بس، وحافظ عليه سري.

## التشغيل محليًا

```bash
npm install
npm run dev
```

## البناء والنشر (Build & Deploy)

```bash
npm run build
```

هيطلعلك فولدر `dist`، ارفعه على أي استضافة استاتيك زي Netlify أو Vercel (سحب وإفلات الفولدر كفاية في Netlify Drop مثلاً: https://app.netlify.com/drop).

## أول استخدام بعد التجهيز

1. سجّل دخول بكود صاحب الشركة (Owner PIN).
2. روح تبويب **"الورش"**، وضيف كل ورشة باسمها وكود دخول ليها (PIN).
3. ابعت لكل مسؤول ورشة رابط الموقع + كود ورشته بس.
4. كل مسؤول هيدخل بكوده، ويضيف عماله من تبويب **"الإدارة"**، وبعدين يسجل حضور وانصراف من تبويب **"اليوم"**.
5. إنت (صاحب الشركة) هتشوف كل حاجة مجمعة أول بأول من تبويبات **"اليوم"**، **"السجل"**، **"التقارير"**.

## تسجيل الخروج

في أعلى الصفحة زرار **"خروج"** — لو الجهاز مشترك بين أكتر من حد، اعمل خروج بعد ما تخلص عشان محدش يستخدم الكود بتاعك.
